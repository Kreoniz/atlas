# Атлас

Локальный трекер устной игры в страны и столицы. Нажмите на строку, чтобы вычеркнуть названную страну и подсветить её на карте. Столица показана под названием, флаг увеличивается при наведении. Enter отмечает первый результат поиска, Esc очищает поле. Кнопка «Сбросить» в шапке удаляет отметки после подтверждения. Масштаб карты меняется колёсиком или кнопками, приближённую карту можно перетаскивать. Включите «Автозум», чтобы карта приближала страну при отметке.

Русский интерфейс и тёмная тема включены при первом запуске. Прогресс, язык и тема сохраняются в браузере. Поиск принимает русские и английские названия стран и столиц. Фильтр под поиском меняет список и карту. Наведите указатель на страну на карте, чтобы увидеть её столицу, флаг и статус. Кнопка «Последняя» выделяет последнюю отмеченную страну. Сервер приложения и учётная запись не нужны.

## Запуск

Нужен [Vite+](https://viteplus.dev/guide/).

```sh
vp install
vp dev
```

`vp run check` проверяет типы, `vp build` собирает статический сайт в `dist/`.

## Данные

- 195 ответов соответствуют 193 членам ООН и двум государствам-наблюдателям. [ООН](https://www.un.org/tr/node/44724)
- Геометрия карты подготовлена из общедоступных данных Natural Earth 5.1.2, слоёв Admin 0 Countries и Tiny Countries 1:50m, в равновеликой проекции Equal Earth. Территории вне списка ответов показаны нейтральным цветом. [Natural Earth](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/) · [Equal Earth](https://proj.org/en/stable/operations/projections/eqearth.html)
- Буквы и цифры набраны локальным шрифтом [Golos Text](https://github.com/googlefonts/golos-text), иконки из [Lucide](https://lucide.dev/).
- Флаги из [flag-icons](https://github.com/lipis/flag-icons).
